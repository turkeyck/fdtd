# 3D Yee FDTD — oblique plane wave with PBC + CPML + TF/SF

Self-validating 3D FDTD in C (double precision) for a plane wave obliquely incident in vacuum and on an
n = 1.5 half-space, with Python post-processing (numpy + matplotlib only) and a Meep cross-check.

- Requirements: [`SPEC.md`](SPEC.md) · Derivations: [`derivation.md`](derivation.md) ·
  Results: [`validation_report.md`](validation_report.md) (tables + figures, generated from `results/*.json`)

## Layout

| Path | Purpose |
|---|---|
| `fdtd3d_oblique.c`, `Makefile` | solver: Yee update, x/z PBC (ghost layers), y-CPML, TF/SF plane fed by an exact 1D modal line, on-the-fly DFT, diagnostics |
| `fdtd_theory.py` | discrete dispersion, s/p basis, analytic Yee fields, exact discrete Fresnel |
| `fdtd_io.py` | run the solver (with result caching) and read its outputs |
| `analyze.py` | analysis library (mode projection, echo removal, 3D phase fit, divergence, conserved flux) + CLI |
| `meep_ref.py`, `compare.py` | Meep reference runs and the Level 3 comparison |
| `tests/` | one script per validation level, `run_all_regression.py`, `make_report.py` |
| `runs/`, `results/`, `figures/` | simulation outputs, JSON results, figures (all regenerated by the scripts) |

## Build and run (WSL Ubuntu or Linux)

```bash
make
python3 tests/run_all_regression.py
```

Each level on its own:

```bash
python3 tests/level0_exact_injection.py
python3 tests/level0b_multistep.py
python3 tests/level_cpml_stability.py
python3 tests/level1_leakage.py
python3 tests/level1_all.py
python3 tests/level2_fresnel.py
python3 tests/level3_meep.py
python3 tests/make_report.py
```

`python3 analyze.py --level 0|1|2|all` runs the Level 0–2 scripts in order. `run_all_regression.py --fresh`
forces every simulation to re-run (default reuses a run only if its arguments match and the binary is not newer);
`--continue` keeps going after a failure for diagnosis. Windows without WSL: `mingw32-make CC=gcc EXE=.exe`
(C99 + libm only; the Python scripts expect the binary name `fdtd3d_oblique`).

Meep (Level 3) is not needed for Levels 0–2. It was installed with micromamba:

```bash
micromamba create -p ~/micromamba/envs/mp -c conda-forge "pymeep=*=nompi*" python=3.11 numpy matplotlib
```

and is located through `MEEP_PYTHON` (default `~/micromamba/envs/mp/bin/python`); without it Level 3 reports BLOCKED.

## Physical units: wavelength / angle / grid → field maps (`oblique.py`)

```bash
python3 oblique.py --wavelength 530nm --angle 30 --grid lambda/20
python3 oblique.py --wavelength 1.55um --angle 45 --azimuth 20 --grid 25nm --pol s
python3 oblique.py --angle 37 --dry-run
```

Converts the physical request into solver parameters (Δ in nm, Δt in fs, periods Lx/Lz and orders m/n so that
kx = 2πm/Lx, kz = 2πn/Lz reproduce θ within `--angle-tol`), runs the solver, fits the phase fronts as a check, and
writes `figures/oblique/<tag>_{s,p}_E.png` plus `<tag>.json`. Because the equations are scale-invariant, the
wavelength only changes units. With periodic x/z, not every angle fits exactly on the grid: the realized angle,
its error, and the lattice phase-front angle (numerical dispersion) are all reported. `--dry-run` prints only the
conversion. Other options: `--tf`, `--sf` (lengths in wavelengths), `--max-cells`, `--tiles`.

## Solver arguments (`./fdtd3d_oblique key=value ...`)

Units: c = ε0 = μ0 = 1, λ0 = 1. Main keys (defaults in brackets): `nl` cells per λ0 [20], `S` [0.5], `Lx` [2], `Lz` [3],
`m`, `n` [1, 1], `pol` s|p, `npml` [20], `sf`, `tf` SF/TF lengths in cells [20, 200], `kappa_max` [5], `alpha_max` [0.1π],
`eps2` and `y1` medium permittivity and interface offset from y0 in cells, `ifmode` a (arithmetic mean) | s (staircase),
`inc` a (modal line) | n (analytic×ramp) | 0, `ky` d|c (analytic mode only), `ramp` e (erf, t0=20, τ=4 T0) | r (raised cosine),
`off_t` switch-off time, `nsteps`, `dft0`/`dft1` DFT window in steps, `yplanes` comma list, `zk`/`xi` x–y and y–z slices,
`energy_every`, `div_every`, `snap`, `dump`, `out`.

Outputs in `out/`: `meta.json` (grid, Δ, Δt, Yee offsets, k, E0/H0, all parameters), `dft_<slice>.bin`
(complex128 phasors, six components, F with f(t) = Re[F e^{-iω0 t}]), `dft_aux.bin`, `log.csv` (SF max field, Yee energy,
divergence), optional `snapshots.bin`, `fields_final.bin`.
